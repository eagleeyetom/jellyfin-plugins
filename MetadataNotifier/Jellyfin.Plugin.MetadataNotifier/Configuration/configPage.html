Metadata Notifier

Sends on-screen toast notifications when playback starts on any client, displaying HDR metadata systems (HDR10+, Dolby Vision, HDR10, HLG, and SDR), audio codecs, and transcoding status.

General

Do not show notifications for audio tracks, albums, or songs.
Displays a toast whenever the viewer switches the audio track mid-playback.

Information to Display

Custom Notification Template

Customize the format and order of toast items. Available variables: {hdr}, {audio}, {playback}, {bitrate}, {title}. Leave empty to use the standard bullet-separated layout.

Library Exclusions

Select libraries where notifications should be enabled (uncheck to exclude).

User Exclusions

Select users for whom notifications should be enabled (uncheck to exclude).
