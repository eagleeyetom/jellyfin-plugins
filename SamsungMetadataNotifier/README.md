# Samsung Metadata Notifier Plugin for Jellyfin

Sends on-screen toast notifications when playback starts on Samsung TVs (and other clients), displaying HDR metadata systems (HDR10+, Dolby Vision, HDR10, HLG, and SDR), audio codecs (TrueHD Atmos, DTS-HD MA, etc.), and transcoding status.

## Features

- **Samsung TV Optimization:** Automatically detects Samsung Tizen clients where native metadata indicators are missing.
- **HDR & Metadata Detection:** Identifies HDR10+, Dolby Vision, HDR10, HLG, and SDR.
- **Audio Codec & Channels:** Displays audio formats including TrueHD Atmos, DTS-HD MA, DTS:X, AC3, E-AC3, AAC, and channel layouts (5.1, 7.1, etc.).
- **Transcoding Status:** Reports whether playback is Direct Play, Direct Stream, or Transcoding (Video/Audio).
- **Fully Configurable:** Customize notification duration, target clients, and displayed information categories.
