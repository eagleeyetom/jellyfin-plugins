Jellyfin's web/Tizen player ignores {\anN} positioning in SRT, and ASS tracks always use the style from the file (the client's subtitle appearance settings only live on the device and never reach the server). For every user with an enabled style below, this plugin styles subtitles on the fly: positioned SRT tracks are served as ASS with that style, and white ASS tracks are recoloured. Users without a style get Jellyfin's normal subtitles. No files are written.

When unchecked, every SRT track in the selected languages is styled (and the client's own SRT appearance settings stop applying).

User styles

Click a user to edit their style. Users with a style are listed first.
Maintenance and old file mode
Jellyfin names cached subtitles by stream index; adding or removing external subtitle/audio files shifts the indices and the cache then serves the wrong language. The scheduled task renames the cache files to match.
The scheduled task extracts subtitles that are not cached yet (reads the whole video file).
When unchecked, the scheduled task removes .ass files this plugin wrote earlier.
